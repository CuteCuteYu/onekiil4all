# 检索语法速查

用于精确定位公开信息。DuckDuckGo 与 Bing 基本通用；语法失效时改用更朴素的关键词组合。

| 语法 | 作用 | 示例 |
|---|---|---|
| `site:` | 限定域名 | `site:example.com 年报` |
| `filetype:` | 限定文件类型 | `filetype:pdf 白皮书 新能源` |
| `intitle:` | 标题含该词 | `intitle:"年度报告"` |
| `inurl:` | URL 含该词 | `inurl:press release` |
| `"..."` | 精确短语 | `"某某研究院"` |
| `-` | 排除词 | `苹果 -手机` |
| `OR` | 或（需大写） | `(泄漏 OR 泄露)` |

## 常用组合

- **官方一手信息**：`site:<官方域名> <主题>` —— 优先采信
- **公开文档**：`filetype:pdf <主体> 年报 OR 招股书 OR 白皮书`
- **人物公开信息**：`"<姓名>" (简历 OR 演讲 OR 访谈) <组织>`
- **机构公开信息**：`"<机构名>" site:gov.cn` / `site:edu.cn`
- **网络资产**：`"<domain>" (certificate OR subdomain OR whois)` —— 仅引用公开结果
- **时间限定**：把 `Get-Date` 得到的年月直接写进查询，如 `<主题> 2026年10月`

## 使用要点

1. **一轮中文、一轮英文**，两轮结果常互补
2. 命中太少 → 减词；命中太泛 → 加 `site:` 或 `intitle:`
3. 结果务必点开原文（`web_fetch` / `ddg_fetch_content`）核对，不要只依赖搜索摘要
4. 拿不到公开结果时**如实说明**，不要用推测填补
