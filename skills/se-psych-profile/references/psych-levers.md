# 心理杠杆清单与逐句标注方法

分析消息样本时逐项对照本清单。**命中必须有原文依据**；未命中的杠杆不要硬套。

## 一、Cialdini 六原则（核心清单）

| 杠杆 | 机制 | 消息中的典型信号 |
|---|---|---|
| **权威 Authority** | 屈从于权威身份 | 自称公检法/银行/平台官方/领导；出示"工号""通缉令""红头文件"；使用官方术语堆砌 |
| **紧迫 Urgency/Scarcity** | 时间压力压缩理性思考 | "24小时内""马上""立即""过期作废""最后X个名额""限时" |
| **社会认同 Social Proof** | 从众心理 | "很多人都在用""XX也参加了""大家都在抢" |
| **互惠 Reciprocity** | 欠人情后顺从 | 先给小利（红包/优惠券/免费服务）再提要求 |
| **喜好 Liking** | 对喜欢的人放松警惕 | 过度恭维、快速拉近距离、冒充同乡/同好/共同熟人 |
| **承诺一致 Commitment** | 已承诺后难以反悔 | 引导先做小动作（"先填个表""先付1元验证"）再逐步加码 |

## 二、扩展情绪杠杆

| 杠杆 | 典型信号 |
|---|---|
| **恐惧 Fear** | 威胁账户冻结/征信受损/逮捕/影响家人；制造灾难想象 |
| **贪婪 Greed** | 稳赚不赔/内幕消息/高额返利/刷单返现 |
| **好奇 Curiosity** | "你有一条未读密令""猜猜我是谁""点击查看" |
| **希望/情感依赖** | 长期嘘寒问暖后引导投资（杀猪盘特征）；"我带你赚钱" |
| **羞耻 Shame** | 涉及隐私把柄、"不给钱就发给通讯录所有人"（敲诈类） |
| **混淆 Confusion** | 术语轰炸、复杂操作步骤、多平台跳转让受害者来不及思考 |
| **孤立 Isolation** | "此案涉及机密，不得告知任何人包括家人"（切断求证渠道） |

## 三、辅助识别信号（非心理杠杆，但常伴随出现）

- **切断核实渠道**：不让挂电话、不让告诉家人、只能加"官方QQ"
- **制造非常规沟通**： insistence on 用 QQ/微信而非官方 App 处理"官方业务"
- **语言指纹异常**：称呼错位（自称银行却用口语）、标点混乱、模板痕迹（多个受害者收到同样句式）、繁简混用
- **身份不可验证**：拒绝视频、拒绝回拨、提供的"证据"无法在官方渠道查证

## 四、逐句标注方法

对样本每一句（或多轮对话的每一轮）：

1. **引用原文**（截取关键句，过长可节选）
2. **判手法**：命中的杠杆/信号（可多个）；无手法则标"中性过渡"（话术节奏需要，降低戒心）
3. **找破绽**：这句话哪里经不起核实（身份？渠道？逻辑？）

### 标注示例（虚构样本，仅作格式示范）

> "我是反诈中心的民警，你名下的电话卡涉嫌洗钱案件。"
- 手法：**权威**（自称民警）+ **恐惧**（涉嫌犯罪）
- 破绽：公检法不会通过电话/微信办案；真实案件会当面送达文书

> "为了配合调查，请不要把这件事告诉任何人。"
- 手法：**孤立**（切断求证渠道）+ **权威**（以办案纪律包装）
- 破绽：恰恰是怕你向家人/官方核实

## 五、强度评级

- **高**：该杠杆是推动核心动作（转账/点链接/给验证码）的直接动力
- **中**：显著辅助施压或建立信任
- **低**：轻度使用或仅一笔带过
