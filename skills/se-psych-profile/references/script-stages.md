# 话术五阶段模型与角色原型库

## 一、话术五阶段模型

社会工程学/诈骗话术通常遵循以下阶段推进。判定时给依据，跨阶段样本标出"当前所处阶段"与"已完成的阶段"。

### 阶段 1：接触（Hook）
- **目的**：建立初始联系，筛选目标
- **典型信号**：陌生加好友、"猜猜我是谁"、错发消息钓回复、招聘/中奖/快递问题开场
- **破绽密度**：身份信息模糊，主动索要联系方式

### 阶段 2：养熟（Grooming / Rapport）
- **目的**：建立信任与情感联结
- **典型信号**：日常嘘寒问暖、分享"生活照"、倾听陪伴、塑造专业/成功人设、长时间低压力接触（可持续数周）
- **典型骗局**：杀猪盘、冒充熟人
- **破绽密度**：拒绝视频通话、人设过于完美、回避见面

### 阶段 3：施压（Pressure）
- **目的**：抛出核心诉求，用情绪压倒理性
- **典型信号**：机会（稳赚内幕）或危机（账户涉案）双路径登场；制造紧迫；开始要求具体操作
- **破绽密度**：收益/危机与官方渠道说法不一致；要求脱离官方平台沟通

### 阶段 4：行动（Action）
- **目的**：引导完成关键动作
- **典型信号**：转账/充值/点链接/给验证码/下载 App/开屏幕共享
- **破绽密度**：收款账户为个人账户；链接域名与官方不符；要求的操作超出对方声称身份的权限

### 阶段 5：脱身（Exit）
- **目的**：防止受害者及时醒悟
- **典型信号**：要求"保密到账"、继续小额返利拖延提现、失联拉黑、二次话术（冒充客服"帮你追回损失"= 诈骗续集）
- **破绽密度**："追回被骗资金"的客服本身就是新的诈骗

## 二、冒充角色原型库

| 原型 | 常见场景 | 匹配特征 |
|---|---|---|
| **公检法** | "涉嫌洗钱/案子" | 通缉令图片、安全账户、要求保密、转接"警官" |
| **平台客服** | 退款/会员误开通/快递理赔 | 知道部分真实订单信息、屏幕共享、"取消扣费" |
| **领导/老板** | 企业内诈骗 | 换头像换昵称、"在开会不方便通话"、要求垫付/转账 |
| **恋人/知己** | 杀猪盘 | 长期情感投入、"我带你投资"、拒绝视频 |
| **投资导师** | 荐股/虚拟币 | 晒收益图、内幕消息、小额返利尝甜头 |
| **技术支持** | 冒充银行/运营商 IT | 术语轰炸、"账户异常需配合操作"、索要验证码 |
| **熟人（盗号）** | QQ/微信盗号 | 突然借钱、理由紧急、拒绝语音核实 |
| **公检法二次诈骗** | 追回损失 | 主动联系受害者、"立案成功可退款"、先交"手续费" |

## 三、组合判定要点

1. **阶段 × 原型交叉验证**：如"自称公检法 + 直接要求转账"跳过了养熟，通常伴随高强度恐惧杠杆——这种"加速推进"本身就是破绽
2. **多轮样本按时间线切段**：每轮标注所处阶段，观察话术如何随受害者反应调整（如犹豫时加紧迫、追问时给伪造证据）
3. **角色原型可叠加**：如"恋人 + 投资导师"（杀猪盘标配）、"客服 + 技术支持"（退款诈骗变体），全部列出
