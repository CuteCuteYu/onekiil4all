# 社会工程学消息心理画像

对用户提供的可疑消息样本（聊天记录 / 短信 / 邮件 / 客服对话）做**纯防御视角**的心理画像分析：
识别攻击者使用的心理杠杆、话术所处阶段、冒充角色原型，并逐句标注操纵手法与破绽。

## 0. 红线（必做自查）

- **只分析**：用户提供的消息样本、公开披露的案例
- **不生成**：不产出任何可用于实施操纵的新话术、剧本、跟进消息
- **不建档**：不为消息中的真实个人建立心理档案；"易感性"只做群体维度描述（如"独居老人""求职者"），不指向具体某人
- 遇到"帮我构造/续写/优化这条骗人消息"类请求 → 拒绝并说明可提供的替代帮助（拆解该话术、给出识别要点）

## 1. 流程

### 步骤一：确认样本与背景（必做）

先确认三件事，用户未说明时按最可能假设推进并显式标注：
1. **样本来源**：短信 / 邮件 / 即时聊天 / 客服对话 / 公开案例
2. **用户与对方的关系**：陌生 / 网友 / "领导" / "客服" / "熟人（疑似被盗号）"
3. **当前状态**：仅收到 / 已回复 / 已有损失

样本信息不足（如只有一句话）时，明确说明分析置信度受限，不要脑补剧情。

### 步骤二：调用分析框架（按图索骥）

**必读** `references/psych-levers.md`（心理杠杆清单 + 逐句标注方法），
需要判定话术阶段与角色原型时读 `references/script-stages.md`。
分析时对每一条结论都引用样本原文作为依据，**没有原文支撑的手法不要写**。

### 步骤三：产出画像卡片（固定结构）

```markdown
## 心理画像报告

**样本概况**：类型 / 轮数 / 我方角色假设 / 分析时间（先 Get-Date）

### ① 话术阶段判定
所处阶段 + 依据（对照五阶段模型：接触 → 养熟 → 施压 → 行动 → 脱身）

### ② 冒充角色原型
命中的原型（公检法 / 客服 / 领导 / 恋人 / 投资导师 / 技术支持 / 熟人盗号 …）+ 原型特征匹配点

### ③ 心理杠杆命中
| 杠杆 | 原文依据 | 强度（高/中/低） |
（Cialdini 六原则 + 恐惧/贪婪/紧迫/从众/好奇/权威转移等扩展项）

### ④ 逐句手法标注
> "原文引用"
- 手法：xxx ｜ 破绽：xxx
（每句标注；无手法的中性句也标"中性过渡"，体现话术节奏）

### ⑤ 目标人群易感性（群体维度）
这套话术对哪类人群最有效、为什么（不指向具体个人）

### ⑥ 识别与应对要点
这套话术的破绽清单 + 核实方法（官方渠道回拨 / 不点链接 / 转账冷静期 …）

### ⑦ 置信度与局限
高/中/低 + 样本局限（轮数少 / 缺上下文 / 单侧记录）
```

### 步骤四：入图沉淀（画板已保存时主动提议）

画像完成后，若 `graphrag_status` 显示画板已保存，**主动询问**用户是否把结果沉淀为知识图谱：
- 节点：骗术模式（FraudPattern）、命中的心理杠杆（PsychLever）、阶段（ScriptStage）、角色原型（Persona）
- 关系：`FraudPattern --USES--> PsychLever`、`FraudPattern --STAGE--> ScriptStage`、
  `FraudPattern --PERSONA--> Persona`
- 用 `graph_add_node` / `graph_add_edge` 写入，之后可用 `graphrag_query` 检索问答

用户未同意时不要自动写入。

## 2. 质量要求

- **逐句标注必须引用原文**，禁止虚构样本里不存在的内容
- 区分**事实**（样本里写了什么）与**推断**（这说明什么手法），推断需给依据
- 命中多个角色原型时全部列出，按匹配度排序，不强行归一
- 若样本明显是正常通信（无操纵特征），如实说"未检出明显操纵手法"，不要为了产出而过度解读
- 长样本（多轮聊天）先给时间线梳理，再按轮次标注
